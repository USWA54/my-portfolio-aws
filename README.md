# My Portfolio Website — AWS S3

A personal portfolio website built using HTML and CSS and hosted on Amazon Web Services (AWS).

## Live Website

[Visit My Portfolio](http://uswa-portfolio-2026.s3-website.ap-south-1.amazonaws.com)

## Technologies Used

- HTML5
- CSS3
- Amazon S3
- AWS Management Console

## AWS Configuration

- **AWS Service:** Amazon S3
- **Bucket Name:** `uswa-portfolio-2026`
- **AWS Region:** `ap-south-1` (Asia Pacific — Mumbai)
- **Hosting Type:** Static Website Hosting
- **Index Document:** `index.html`

## Project Files

- `index.html` — Main portfolio webpage
- `style.css` — Website styling and layout
- `README.md` — Project documentation

## Project Overview

This project demonstrates how to host a static website using Amazon S3. The HTML and CSS files are stored in an S3 bucket, and the website is accessible through the S3 static website endpoint.

## What I Learned

- Creating and configuring an Amazon S3 bucket
- Hosting a static website on AWS
- Uploading website files to an S3 bucket
- Configuring the index document for website hosting
- Accessing a hosted website through its S3 website endpoint
